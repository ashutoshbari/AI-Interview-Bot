# 🤖 AI Interview Assistant

🚀 Transforming traditional interviews into intelligent, automated AI-driven experiences.

---

## 🧠 Overview

AI Interview Assistant is a **production-level AI system** that automates the candidate interview process using advanced AI models.

The system:
- 📄 Analyzes candidate resumes  
- 💬 Conducts real-time AI interviews (chat + voice)  
- 🧠 Generates dynamic questions (no hardcoding)  
- 📊 Evaluates answers and provides feedback  

---

## ⚡ Key Features

✨ Resume-based dynamic question generation  
🎤 Real-time interview (Chat + Voice support)  
📊 Automated scoring & performance evaluation  
📈 Dashboard with candidate analytics  
📬 Email automation (feedback + reminders)  
📌 Interview status tracking (Completed / Incomplete)  
⚡ Performance monitoring (FPS, latency, system metrics)  
🎨 Modern AI UI with animations  
🖥️ Fully local AI support using Ollama (llama3)  

---

## 🔄 Interview Flow

1️⃣ Upload Resume 📄  
2️⃣ AI analyzes candidate profile 🧠  
3️⃣ AI starts interview 🎤  
4️⃣ Candidate answers questions 💬  
5️⃣ AI evaluates performance 📊  
6️⃣ Final report + feedback generated 📈  
7️⃣ Email sent automatically 📬
